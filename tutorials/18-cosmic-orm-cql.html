COSMIC ORM & CQL

COSMIC is the OASIS ORM, and CQL is its query language: one JSON query that runs natively on MongoDB, SQLite, Neo4j, blockchains, IPFS and more than a hundred other providers. HyperDrive keeps the copies in step, so you query one model and OASIS decides where the data lives.

What you'll build

  • Run your first CQL query in the browser sandbox
  • Filter, order and page holons on a chosen provider
  • Count and aggregate with scalar and grouped queries
  • Run the same query from JavaScript and from the STAR CLI
  • Watch HyperDrive fail over when a provider goes offline

Why CQL

Every OASIS provider stores holons in its own way: documents in MongoDB, rows in SQLite, nodes in Neo4j, records on chain. CQL describes what you want as plain JSON, and WEB4 compiles it into the provider's own query. Because a query can never contain code (no C#, SQL or Cypher), it is safe to accept from any client, and the same query works on every provider.

Try It in the Sandbox

Open web4.oasisomniverse.one. It signs you in as a demo avatar (through POST /api/sandbox/session), lists the providers you can query and lets you run each query kind. It is a shared public playground, so keep anything private out of it.

Your First Query

query.json
{
  "provider": "MongoDBOASIS",
  "filters": [
    { "field": "Name", "scalar": "String", "operator": "Contains", "value": "coffee" }
  ],
  "orderBy": "Name",
  "take": 10
}

Each filter names a field (or a typed metadataPath), a scalar type, an operator such as Equal, Contains or GreaterThan, and a value. Filters are ANDed together; put alternatives in anyOf to OR them.

From JavaScript

cql.js
import { OASISClient } from '@oasisomniverse/web4-api';

const oasis = new OASISClient({ baseUrl: 'https://api.web4.oasisomniverse.one' });
await oasis.auth.login({ username, password });

// POST /api/data/query-cql  (a new Idempotency-Key is sent with each call)
const { result } = await oasis.data.query({
  provider: 'MongoDBOASIS',
  filters: [{ field: 'Name', scalar: 'String', operator: 'Contains', value: 'coffee' }],
  take: 10
});

// POST /api/data/query-cql/scalar : how many match?
const count = await oasis.data.scalar({
  provider: 'SQLLiteDBOASIS',
  operation: 'LongCount',
  filters: [{ field: 'Name', scalar: 'String', operator: 'StartsWith', value: 'Quest' }]
});

Other query kinds have their own methods: indexed, projection, grouped, set, join, composition and federation (one query across several providers). Their request shapes are on WEB4's Swagger page.

Watch HyperDrive Fail Over

In the sandbox, take a provider offline (POST /api/sandbox/providers/MongoDBOASIS/offline) and run your query again. HyperDrive serves it from the next provider in the fail-over list, and GET /api/sandbox/faults shows what it handled. Bring it back with /online. On your own node the same behaviour comes from the AutoFailOver, AutoReplication and AutoLoadBalance settings in OASIS_DNA.json.
